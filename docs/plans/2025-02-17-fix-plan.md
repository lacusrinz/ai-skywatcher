## Problem Statement

During browser testing of the interactive optimization features, three issues were discovered:

### Issue 1: Timeline Slider Shows All Targets Instead of Recommendations
**Symptom**: When dragging the time slider, the sky map displays ALL deep sky targets instead of only the RECOMMENDED targets.

**Root Cause**: `updateSkyMapForTime()` function (main.js:1072-1088) calls `API.getSkyMapData()` which loads all sky map targets, overwriting the recommended targets that were previously filtered.

**Impact**: Users lose the recommendation context when adjusting observation time, making it difficult to evaluate when specific recommended targets will be best positioned.

---

### Issue 2: FOV Overlay Not Displaying
**Symptom**: When dragging the FOV preview box to a target, the dashed circle overlay showing the target's real size does not appear.

**Potential Causes**:
- Threshold distance in `checkFovTargetOverlap()` may be too large
- Detection logic may have edge cases
- Render order or canvas context issues

**Impact**: Users cannot visually compare target size to their equipment's FOV, which is the primary purpose of this feature.

---

### Issue 3 (Enhancement): Auto-Position FOV Box on Target Click
**Current Behavior**:
- Clicking a recommendation card → Focuses camera on target (✓ implemented)
- Clicking a target on sky map → Does nothing (calls `onTargetSelect` callback but no FOV movement)

**Desired Behavior**:
- Clicking a recommendation card → Focuses camera + moves FOV box to target
- Clicking a target on sky map → Moves FOV box to target

**Impact**: Improved workflow for comparing target sizes across different equipment configurations.

### Phase 2: Debug and Fix FOV Overlay

**Approach**: Add logging and adjust detection threshold to ensure overlay appears when FOV box is near target.

**File**: `frontend/src/scripts/utils/canvas.js`
**Function**: `checkFovTargetOverlap()` (lines 498-551)

**Current Issue Analysis**:
```javascript
const fovPixelSize = this.getFovPixelSize();
const thresholdDistance = Math.min(fovPixelSize.width, fovPixelSize.height) * 0.5;
```

The threshold is 50% of the smaller FOV dimension, which may be too large. For a 10.3° × 6.9° FOV:
- Smaller dimension = 6.9° FOV in pixels
- Threshold = 50% of that = 3.45° FOV equivalent
- This means the FOV box center must be VERY close to the target

**Solution**:
1. Increase threshold to 100% (entire FOV box area)
2. Add console logging for debugging
3. Ensure overlay renders on top of other elements

**New Code**:
```javascript
checkFovTargetOverlap() {
  const { fovFrame } = this.state;
  const { targets } = this.state;

  if (!targets || targets.length === 0) return null;

  const fovCenter = this.projectFromCenter(
    fovFrame.center.azimuth,
    fovFrame.center.altitude
  );

  if (!fovCenter.visible) return null;

  const fovPixelSize = this.getFovPixelSize();

  // CHANGED: Use 100% of larger dimension (more permissive)
  const thresholdDistance = Math.max(fovPixelSize.width, fovPixelSize.height) * 1.0;

  let closestTarget = null;
  let minDistance = Infinity;

  targets.forEach(target => {
    if (target.altitude <= 0) return;

    const targetPos = this.projectFromCenter(target.azimuth, target.altitude);
    if (!targetPos.visible) return;

    const dx = targetPos.x - fovCenter.x;
    const dy = targetPos.y - fovCenter.y;
    const distance = Math.sqrt(dx * dx + dy * dy);

    if (distance < minDistance && distance < thresholdDistance) {
      minDistance = distance;
      closestTarget = target;
    }
  });

  if (!closestTarget) {
    // CHANGED: Log for debugging
    if (targets.length > 0 && fovCenter.visible) {
      console.log('FOV Overlay Debug: No target found within threshold', {
        threshold: thresholdDistance.toFixed(2),
        visibleTargets: targets.filter(t => t.altitude > 0).length,
        fovCenter: { az: fovFrame.center.azimuth.toFixed(1), alt: fovFrame.center.altitude.toFixed(1) }
      });
    }
    return null;
  }

  const { overlapPercentage, canvasSize } = this.calculateTargetFovRatio(closestTarget);

  // CHANGED: Log successful detection
  console.log('FOV Overlay: Target detected', {
    target: closestTarget.name,
    overlap: (overlapPercentage * 100).toFixed(1) + '%',
    distance: minDistance.toFixed(2)
  });

  return {
    target: closestTarget,
    overlapPercentage,
    canvasSize,
    distance: minDistance
  };
}
```

### Phase 3: Auto-Position FOV Box on Target Click

**Approach**: Add method to animate FOV box to target position, integrate with click handlers.

**File**: `frontend/src/scripts/utils/canvas.js`
**New Method**: `animateFOVFrameToTarget(target, options)`

**Implementation**:

```javascript
/**
 * 将 FOV 框平滑移动到目标位置
 * @param {Object} target - 目标对象 { azimuth, altitude, id, name }
 * @param {Object} options - 选项 { duration, onComplete }
 */
animateFOVFrameToTarget(target, options = {}) {
  const {
    duration = 400,  // 400ms animation (faster than focus)
    onComplete = null
  } = options;

  const startAzimuth = this.state.fovFrame.center.azimuth;
  const startAltitude = this.state.fovFrame.center.altitude;
  const endAzimuth = target.azimuth;
  const endAltitude = target.altitude;

  const startTime = performance.now();

  const animate = (timestamp) => {
    const elapsed = timestamp - startTime;
    const progress = Math.min(elapsed / duration, 1);

    // Ease-out cubic for smooth deceleration
    const eased = 1 - Math.pow(1 - progress, 3);

    // Interpolate angles
    const newAzimuth = this.lerpAngle(startAzimuth, endAzimuth, eased);
    const newAltitude = this.lerp(startAltitude, endAltitude, eased);

    this.state.fovFrame.center = {
      azimuth: (newAzimuth + 360) % 360,
      altitude: Math.max(0, Math.min(90, newAltitude))
    };

    this.render();

    if (progress < 1) {
      requestAnimationFrame(animate);
    } else {
      // Animation complete
      this.onFOVFrameChange?.(this.state.fovFrame.center);

      if (onComplete) {
        onComplete();
      }
    }
  };

  requestAnimationFrame(animate);
}
```
